# agentspec

Shadow specification repository of [agentknit](https://github.com/monperrus/agentknit).

Each agentknit commit that adds a feature creates a spec file
`specs/NNN_<name>.md`, where `NNN` gives the implementation order.
Each fix clarifies one. Every commit carries a `Source-Commit:` trailer that
points to the agentknit commit it mirrors. The files are maintained by a
coding agent via the `shadow-sync` tool. Do not edit them by hand.
